## Production Bug Fix: React Error #310 on Post-Login Redirect
Fixed a "Rendered more hooks than during the previous render" crash that occurred on Vercel right after login (but not on a hard reload). Root cause: `(app)/layout.tsx`, `(auth)/layout.tsx`, and `src/app/page.tsx` all called `redirect()` from `next/navigation` synchronously during render in client components — a known anti-pattern where the thrown `NEXT_REDIRECT` can corrupt hook accounting mid-transition. Replaced all three with the standard client-side pattern: `useRouter().replace()` inside a `useEffect`, rendering `<LoadingSpinner />` while the redirect is pending.
